# agriculturafamiliar1aConexão Campo & Cidade

O Conexão Campo & Cidade é uma plataforma que aproxima pequenos agricultores da população urbana, promovendo a divulgação de produtores locais e facilitando o acesso a informações sobre seus produtos. O projeto busca fortalecer a agricultura familiar, incentivar o consumo consciente e valorizar a produção local, criando uma conexão mais próxima entre quem produz e quem consome
